# Logo Going Through Portal

A Python animation project that takes a custom logo and animates it being pulled through a portal into a new scene.

## Files in This Repository
* **`sucked_through_portal.py`** — The main Python script that generates the animation.
* **`Sucked Through the portal.mp4`** — The rendered video output showing the final portal effect.

## How to Run the Code

### 1. Prerequisites
Make sure you have Python installed on your computer. You will also need to install the required libraries used in the script (update the list below if you used different ones):

```bash
pip install opencv-python numpy pillow
```

### 2. Run the Script
1. Download or clone this repository to your computer.
2. Place your logo image in the same folder (or update the file path in the code).
3. Run the script from your terminal:

```bash
python sucked_through_portal.py
```

## Preview
To see the final result without running the code, click on **`Sucked Through the portal.mp4`** in the file list above to view or download the video.
